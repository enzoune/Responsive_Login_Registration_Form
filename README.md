# 🔐 Dual Authentication Interface (Login & Registration)

> Um componente de autenticação moderno e responsivo que integra fluxos de Login e Cadastro em uma única interface inteligente, utilizando lógica de estado nativa em CSS3.

## 📖 Sobre o Projeto

Este projeto integra o meu portfólio de estudos em **Programação Full-Stack**. O objetivo foi desenvolver um sistema de formulários de autenticação que prioriza a fluidez na navegação do usuário. 

A grande inovação técnica aqui é a alternância entre as telas de **Login** e **Cadastro** sem a necessidade de recarregar a página ou utilizar scripts complexos, proporcionando uma experiência de usuário (UX) comparável a aplicações modernas de página única (SPA).

## ✨ Destaques e Diferenciais Técnicos

* **Gerenciamento de Estado sem JavaScript:** Uso estratégico do "Checkbox Hack" (`input type="checkbox" id="check"`) para alternar a visibilidade e transição entre os formulários de forma declarativa.
* **Formulários Estruturados e Semânticos:** Implementação de campos de entrada específicos para e-mail e senhas, incluindo um fluxo de confirmação no cadastro para garantir a integridade dos dados.
* **Interface Orientada a Conversão:** Inclusão de elementos essenciais de usabilidade, como links de recuperação de senha e alternadores de contexto ("Cadastre-se" e "Login").
* **Arquitetura de Layout Flexível:** Uso de uma estrutura de contêiner central (`.container`) que organiza os formulários (`.login` e `.registration`) de maneira modular, facilitando a manutenção.
* **Design Responsivo:** Componente projetado para se adaptar perfeitamente a diferentes tamanhos de tela, mantendo a legibilidade e facilidade de interação em dispositivos móveis.
* **Organização Profissional:** Separação clara entre a marcação estrutural (`index.html`) e a identidade visual localizada no diretório `css/style.css`.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e lógica de controle de estado nativa.
* **CSS3:** Estilização avançada, transições de interface e design responsivo.
